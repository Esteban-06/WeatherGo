Create a database schema for an application that suggests outfit choices based on current weather conditions based on this mockup. Each user has their own table with a UserID field, Username field, and Clothing Items field. Each item in the Clothing Items field will have their own separate table. Within each clothing item’s table there should be a Clothing Name field, a IfPant field, a IfLongSleeveShirt field, a IfShortSleeveShirt field, a IfShort field, a IfJacket field, a IfHoodie field, a Breathable field, a Warming field, and a Cooling field. The a IfPant field, a IfLongSleeveShirt field, a IfShortSleeveShirt field, a IfShort field, a IfJacket field, a IfHoodie field, a Breathable field, a Warming field, and a Cooling field should all be boolean fields while the the rest are Text fields.

Useful Info: 
Our app is called WeatherGo. WeatherGo is an application designed to help users make informed clothing decisions using real-time weather data and personalized wardrobe information. While traditional weather applications provide forecasts and environmental conditions, users are still responsible for determining how those conditions should influence their daily attire.
WeatherGo addresses this gap by combining weather intelligence with a personalized digital wardrobe. Users can create a wardrobe profile containing clothing items and associated attributes such as warmth, breathability, waterproofing, and formality. Using current weather conditions, the system generates practical clothing recommendations tailored to each user's available clothing. The primary goal of WeatherGo is to simplify daily decision-making, improve preparedness, and help users feel more confident when planning their day.
